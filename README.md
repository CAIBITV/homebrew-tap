# CAIBITV Homebrew Tap

```bash
brew tap caibitv/tap
brew install --cask codeisland-caibitv
```

| Cask | 说明 |
|---|---|
| `codeisland-caibitv` | [CodeIsland](https://github.com/CAIBITV/CodeIsland)，新增会话 token 用量与估算速度，仅支持 Apple 芯片 |
| `itsycal-caibitv` | [Itsycal](https://github.com/CAIBITV/Itsycal)，支持独立时区和地区节假日日历，需 Apple 芯片和 macOS 27 或以上 |
